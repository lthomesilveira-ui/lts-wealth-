# V371 confirmed billing calendar

A whole month between the last old billing date and first new billing date is an intentional no-payment month. Recurrence coverage now keeps it separate from a missing forecast, an owner-cancelled occurrence and an unconfirmed payment. Actual or projected movements retain precedence. Each confirmation is scoped to its owner and card family; later gaps remain visible.

The frontend labels this state “Sem débito”. All existing financial sources, transactions, classification writers and published releases are preserved. Native PostgreSQL checks execute the leased production audit, including other-owner/series isolation, October payment uncertainty, subsequent gaps, ordinary same-month changes, received-movement precedence and replay. Browser checks cover notebook and two mobile viewport sizes using synthetic data; physical-device and private-session evidence remain separate.

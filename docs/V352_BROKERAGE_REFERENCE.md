# Received brokerage reference and dated positions

A newly supplied image shows aggregate portfolio values without the position's own date or the monetary split between RSUs and Cash RSUs. The dated snapshot table requires complete component values and a position date, so inserting the image there would invent evidence. Store a separate owner-scoped reference with a nullable date, its original file digest, observed totals and quantities, and explicitly unknown monetary components.

The existing owner-authenticated wealth reader adds this reference without changing its dated statement, available liquidity, projection schedule, prices, cash or financial history. The Patrimônio RSU view displays the received reference separately, keeps the missing date and missing composition visible, and puts source details under a closed disclosure. The original dated position and planning projections remain available. Historical acquisition payments for the property are labelled as such, and the mortgage's documentary date stays visible.

The private activation compares complete dated snapshots and the existing financial subtrees before and after its one insertion, rejects guessed dates/components and rejects duplicate source digests.

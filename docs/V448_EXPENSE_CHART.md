# V448 expense chart readability candidate

Monthly expense values previously shared narrow columns and wrapped into multiple rows while their text stayed unbroken. This CSS-only candidate keeps the expense chart in a single horizontally scrollable row; each column is at least 96px and expands for its actual label content. It does not shorten, round again, remove or change a financial value, date, category, reader or writer.

V447 assets remain immutable and all JavaScript is byte-preserved. Mobile/current.json remains on V442 until independently coordinated authenticated acceptance. Tests check rendered geometry, extreme labels, compact multi-year series, first/last reachability, viewport overflow and preserved content in Chromium and WebKit. Local browser execution is unavailable because socket creation is denied; CI and authenticated rendered acceptance are separate gates.

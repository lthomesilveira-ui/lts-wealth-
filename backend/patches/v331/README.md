# Original workbook provenance

Later restorations from the owner's original workbook should retain the same
provenance label as earlier restorations. Preserve the existing V226 condition
and recognize subsequent versioned restoration tags. Categories, people, dates,
amounts and source records remain unchanged.

The leased function keeps its owner, OID, grants and other attributes. Advance the
existing read-cache revision only when its definition changes; replay leaves that
revision alone. Eight source and financial fingerprints must remain identical.

Verification compares the complete old and proposed readers on private original
data, checks that only the intended provenance field differs, and reruns the
existing PostgreSQL learning and V312 desktop/mobile regressions. Private data and
the original workbook stay outside this public repository. These checks do not
certify a private browser session or a physical device.

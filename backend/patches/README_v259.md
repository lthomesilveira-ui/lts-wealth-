# V259 — dated brokerage positions after settled redemptions

Current Awards, Cash, Wealth and Planning readers now select the latest validated brokerage position valid on the requested date. A later statement remains separate dated evidence; it does not overwrite the prior anchor. Withdrawal deductions apply only after the selected position date, so a post-redemption position cannot have the same withdrawal deducted again. Historical Flow readers select an anchor per day.

The guarded patch changes fourteen existing functions and preserves their complete ACLs. It adds no endpoint, grant, table, policy or financial bank event. Source reconciliation is a separate private, owner-authorized payload, never published in this repository. It links an existing posted own-account bank credit, appends the supplied brokerage snapshot and current available asset components, and retains the prior statements and individual future vesting schedule. Current Cofrinho values in Wealth and the executive summary follow the existing movement-aware documentary reader.

Future economic position is assembled from corrected available resources, restricted FGTS and the remaining scheduled awards. Previously, it could retain an obsolete intermediate total after the current available position was corrected. Unknown historical positions remain unknown. Statement totals and planning assumptions remain separate; an aggregate screenshot cannot determine individual grant quantities, tax, gross trade proceeds or FX settlement terms.

Before deployment, rollback diagnostics tested the actual authenticated public Cash, Awards, Wealth, Flow and executive-summary readers. All projected days retained their bank positions and scheduled events. Historical bank and dated-resource values preceding the newly confirmed redemption remained unchanged; range-relative display balances were excluded from exact comparison because the prior covered-range memo used a different range origin. The post-deployment authenticated READ ONLY test returned all 730 days of 2026–2027 and verified the current position and future resource arithmetic. Financial bank-event and vesting-source digests stayed exact; anonymous SECURITY DEFINER access remained zero and existing authenticated access counts were unchanged.

The V259 interface assets remain byte-identical to V258 except for the wrapper version label. Earlier releases and the root index are protected. Browser regression uses fixtures and does not substitute for the owner's authenticated sign-in, iPhone or upload acceptance. Source-dependent reconciliation, authentication configuration, cold latency and full isolated restoration remain explicit outstanding work.

The migration leases intentionally reject reapplication. Do not use older release QA amounts as current position assertions.

# Learning for named suppliers

The generic processor guard also suppressed category history for a few fully
named suppliers whose business context had been reviewed. Recognize four exact
descriptor/MCC/provider-category combinations, then let the existing history
reader propose a category. The context helper does not choose a category, product,
person or legal entity. Ambiguous/truncated names, incorrect codes, marketplaces
and unrecognized processors retain their context requirement.

A separate history branch could suggest a merchant's previous spending category
for an unrelated PIX/funding operation. Require that operation's own purpose;
preserve the existing strong same-purchase installment evidence. Suggestions still
require confirmation and never copy a person/property or write a classification.
Owner corrections retain the V319 precedence.

Native PostgreSQL fixtures demonstrate the previous behaviors and verify the
learned suggestions, unrelated funding, strong purchase evidence, unchanged
unaffected suggestions, drift/replay, role isolation and source/financial hashes.
The leased reader keeps all attributes except its body; the new helper is private
and immutable. V312 browser checks cover desktop and mobile with synthetic native
payloads. No private-session, physical-device or production-benchmark claim is made.

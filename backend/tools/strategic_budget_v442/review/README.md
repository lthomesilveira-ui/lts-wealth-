# Isolated reviewed planning candidate

NOT wired into released assets or published UI. This subtree replaces historical-average prescriptions with evidence-backed, explicitly unapproved proposals, preserves approved goals, and exposes unknown coverage. Card received purchases remain commitments even when not installment purchases. Payroll exclusion requires source identity, amount, net-income arithmetic and evidence; lender names alone never suffice.

Reconciliation keeps cash schedule, estimated cash, invoice payments and card competence in separate layers. It never certifies a combined budget total. The browser preview uses synthetic fixtures only. It is a visual/semantic harness, not owner-data validation and not a completed individualized budget. Private household data and proposed actual limits remain outside this repository.
